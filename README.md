# ADOD_Burden-Trend
**Burden and Trend Analysis of Alzheimer's Disease and Other Dementia in West Africa; A Secondary Analysis of Global Burden of Disease (GBD) Data**


Ejiofor Chieloka Faith


## Summary

This project describes and compares the burden (prevalence, incidence, mortality, DALYs) and trend of Alzheimer's disease and other dementias (ADOD) across West African countries, using publicly available Global Burden of Disease estimates. West Africa remains comparatively under-represented in the published GBD-based dementia literature relative to global and other-region analyses, despite reporting some of the lowest recorded age-standardized incidence rates for ADOD globally — a pattern that may reflect underdiagnosis and data sparsity rather than genuinely lower burden.

## Objectives

- Estimate prevalence, incidence, mortality, and DALYs for ADOD across West African countries
- Estimate Annual Percentage Change (APC) and Average Annual Percentage Change (AAPC) in age-standardized rates using joinpoint regression
- Compare country-level and regional (GBD Western Sub-Saharan Africa) estimates against the global estimate
- Describe modifiable risk-factor contributions to ADOD burden where data permit

## Data Source

- **Global Burden of Disease (GBD) 1990-2023 Results**, Institute for Health Metrics and Evaluation (IHME)
- Accessed via [GBD Results Tool](https://vizhub.healthdata.org/gbd-results/)


## Tools

- Microsoft Excel — data cleaning, reshaping, pivot tables, charting
- [NCI Joinpoint Regression Program](https://surveillance.cancer.gov/joinpoint/) — trend analysis (APC/AAPC)
